# My Player: 60-second submission video script

Voice: Mark (or one calm narrator). About 140 spoken words. Captions on. Screen recording of the real app; any replay footage carries its on-screen SAMPLE label.

| Time | On screen | Voiceover |
|---|---|---|
| 0:00–0:07 | Title card: **My Player**, tagline "Shown, not said." | "Anyone can claim a skill. My Player only unlocks the ones you actually show." |
| 0:07–0:17 | Onboarding: photo, name, three skill claims typed in. | "I claim three skills, then upload a short video of myself working." |
| 0:17–0:29 | Analyze running; three stage badges light up with model ids and latency. | "Three Gemini stages read the same video. One logs what's shown versus only said. One challenges it. One answers yes or no for each skill." |
| 0:29–0:43 | **Refusal moment.** Skill A unlocks; Skill B stays locked. Click the lock, the drawer opens, click the timestamp, the video jumps. | "This skill I said out loud, but never showed. So it stays locked, and the drawer shows exactly why, down to the second." |
| 0:43–0:52 | Gate rules / failure states; benchmark tab with real counts or visibly unfilled `[REAL COUNTS]`. | "A tested rule set makes the final call. If anything fails or comes back unsure, the node stays locked." |
| 0:52–1:00 | Card with one locked, one unlocked node. End card: My Player + repo link. | "No scoring people. Just shown versus said, and honest when the evidence isn't there." |

**Rules for the edit:** badges and counts must be from a real run or clearly labeled SAMPLE. No invented numbers, no speed claims, no hype music stings. Keep the locked-node pause.
